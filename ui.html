Загрузите CSV UTF-8 с разделителем «;». Сначала выполните предварительную проверку, затем подтвердите запись в базу. Исходные PDF остаются без изменений.

Ожидание CSV

Источники должны содержать название каталога и номер страницы. Статус engineer_verified обозначает заявление пользователя, а не независимую проверку системой.

Извлечение характеристик из PDF

Выберите документ, выполните анализ таблиц и проверьте извлечённые значения перед импортом. Для графических PDF поддерживается OCR технических таблиц PitON E3: PDF страницы 60–63 (Al и Cu, 400–6400 А).

Выберите каталог.

Изменяйте числовые значения прямо в таблице. Пустые строки — это пропуски OCR, их надо заполнить вручную после сверки с PDF. Все значения имеют статус «Требует проверки». Перед импортом сверяйте с оригинальной страницей. Подтверждение применяет все выбранные значения и может обновить существующие записи.
